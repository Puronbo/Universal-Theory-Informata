# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful of differing viewpoints and experience levels.
- Critique ideas and code, not people.
- No harassment, discrimination, doxxing, or sustained disruption.
- Respect the project's epistemic rules: disagreement about claims should be
  argued with evidence, not personal attacks.

## Enforcement

Maintainers may warn, edit, or remove contributions that violate this code,
and may temporarily or permanently ban repeat offenders. Reports can be sent
privately to the maintainers through GitHub (repository → **Security** →
**Report a vulnerability** if confidentiality is required, or a direct message
to a maintainer otherwise). Reports will be handled discreetly.
